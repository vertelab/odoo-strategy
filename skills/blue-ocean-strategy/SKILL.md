# Blue Ocean Strategy

Find uncontested market space through value innovation.

## Data Sources

- `product.template`: current offering attributes
- `crm.lead`: unmet customer needs
- `sale.order`: which features drive purchases
- `social_marketing.competitor`: competitor offerings

## Four Actions Framework

1. **Eliminate** — which factors that the industry takes for granted should be eliminated?
2. **Reduce** — which factors should be reduced well below the industry standard?
3. **Raise** — which factors should be raised well above the industry standard?
4. **Create** — which factors should be created that the industry has never offered?

## Process
1. Map current competitive landscape (strategy canvas)
2. Identify industry assumptions and trade-offs
3. Apply the four actions framework
4. Design new value curve
5. Validate against CRM data (unmet needs, win/loss reasons)
